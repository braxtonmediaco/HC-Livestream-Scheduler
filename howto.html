Standard Operating Guide

Holy Cross Automated Livestream & Thumbnail Engine

⬅ Return to Scheduler

This tool automates data synchronization between church calendars and design master assets, running batch modifications directly inside your web browser via programmatic Photopea scripts. No external cloud dependencies required.

Phase 1 Initialize Workspace Storage

Before processing data elements or update configurations, you must link your operational filesystem.

  1. Locate the top global utility element bar labeled Project Workspace.
  2. Click the action target Choose Output Folder (To Save Images).
  3. Select your workspace drive location. The browser will issue a permissions pop-up request asking for permission to look at and save data to that folder. Select View Files followed by Save Changes / Allow Access.
Automated Folder Mapping: The engine formats everything inside that directory based on the row date. For instance, a record assigned to 2026-05-31 will generate a top-tier tracking block labeled 2026-05-31/ and build a subfolder called Thumbnails/ inside it to sort your assets.

Phase 2 DataSheet Management

The 1. DataSheet Editor tab functions as the single source of truth for the entire page. All text updates parse straight from this module.

Adding Matrix Data

  • Manual Updates: You can click on the cell spaces underneath the Gospel and Festival column headers to type your texts. Pressing Enter automatically targets the immediate cell layout directly beneath your selection.
  • Automated Date Generation:
    • Use + Add Next Sunday or + Add Next Wednesday to auto-calculate structural tracking points relative to your last row entry.
    • Use + Add Rest of Month to loop and generate entries through the end of the current month.

Importing & Exporting Metadata

  • Clicking ⬇ Download CSV backs up your matrix mapping profile configuration parameters out to a standard flat sheet.
  • Clicking ⬆ Upload CSV parses previous tracking profiles straight back into the live memory loop.

Phase 3 Batch Rendering Engines

Navigate to tab 2. PSD Batch Updater. This runs deep execution layers into the targeted background processing structures.

  1. Target Graphic Assets: Search for built-in template profiles on GitHub via the searchable dropdown selections, or use a Custom Upload button selection to point directly to regional localized layout layers.
  2. Activation Parameters: If you specify a Sermon PSD asset along with your primary **Livestream PSD**, the processor maps out dual rendering tracks. It labels the second set with an appended suffix string: _Sermon.
  3. Execution Loop: Press Process Batch. The background runtime environment hooks directly into Photopea's layer model via internal messaging:
    • The engine maps document trees to find target editable slots explicitly labeled: Gospel, Date, and Festival.
    • It overrides placeholder strings with rows derived directly from your setup datasheet.
    • The system renders out both raw high-fidelity .psd templates and flattened target .jpg print files, sorting them directly into your mapped local drive folders.
Processing Note: Do not close out or change focus away from the active tab panel workspace while the green bar states are ticking. Interrupting browser canvas cycles will drop active macro operations.

Phase 4 YouTube Metadata Injection

Navigate to tab 3. Livestream Scheduler to prepare distribution uploads.

  1. Click Scan Output Folder & Generate Table.
  2. The software will search through local subfolders to verify structural matches for newly outputted image files.
  3. Intelligent Time-Slot Optimization: The scheduling algorithms run checks on dates to map expected service hours automatically:
    • Mid-week / Weekday dates: Default target registers immediately at 6:00 P.M.
    • 1st/3rd Sunday cycles: Evaluates tracking to pre-select morning slots for 9:30 A.M.
    • Alternative Sunday instances: Defaults parameters straight to standard 8:00 A.M.
  4. Copy-Paste Integration: If you need to make corrections, use the manual time drop-down fields to adjust the variables on the fly. This will update the string array output block immediately. Click any gray string element line layout to highlight and copy it cleanly to your clipboard, ready to drop straight into YouTube's broadcast panel.
